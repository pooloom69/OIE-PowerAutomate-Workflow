# Research Request Workflow Automation

## Overview
This project automated the intake and management of research requests during my internship with the Office of Institutional Effectiveness.  
Using Microsoft Power Automate, I built a workflow to streamline faculty/staff requests and improve team efficiency.

## Workflow
1. **Microsoft Forms** – Faculty submit requests via an online form  
2. **Power Automate Flow** –  
   - Generates a unique Request ID  
   - Sends auto-confirmation email to requester  
   - Creates a task in Microsoft Planner for OIE team  
   - Saves responses/attachments to SharePoint  
3. **Microsoft Planner & Teams Integration** – Requests tracked collaboratively until completion  

## Tech Stack
- Microsoft Forms  
- Microsoft Power Automate  
- Microsoft Planner  
- SharePoint / OneDrive  

## Outcomes
- Reduced manual coordination by automating 70% of workflow steps  
- Centralized request tracking for OIE staff  
- Increased transparency for requesters with automated updates
